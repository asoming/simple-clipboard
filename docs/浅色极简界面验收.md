## 范围与依据

用户提供了搜索、紧凑左侧列表、右侧预览的参考图，并明确要求减少无用文字、继续使用浅色。本轮按这个已确认方向重新安排主面板，保留字体可读性、收藏、日期分组和底层数据行为。需求基线为 [PRD v0.13](剪贴板应用-PRD.md) 第 15 节。

将文字收进菜单或提示是界面判断，不代表已证明效率提升。参考图中的来源应用、复制次数等信息没有可靠数据时不展示，也不增加账号、云同步或 OCR。

## 本轮实现范围

- 搜索与类型筛选合为一行，移除重复标题、普通记录状态、数量与整行快捷键说明。
- 左侧单行列表保留日期组和行尾收藏星；长摘要明确省略，选中内容在右侧查看。
- 默认展开预览，新布局记住自身开关偏好。内容与实际元信息分清主次，窄窗改为上下布局。
- 底部用更多、预览、复制图标和格式选择减少文字，保留一个主要「粘贴」按钮；菜单与悬浮提示提供次要操作和快捷键。
- 既有外观选择保留，以浅色作为本轮目视验收的主要结果；不修改用户已保存的外观选择。
- 普通成功反馈简短；暂停、粘贴失败、存储错误和删除确认仍明确展示。

### 与上一版的变化

| 项目 | 0.6.0 | 0.7.0 |
|---|---|---|
| 主面板结构 | 标题／状态、搜索、四个筛选按钮、列表、操作与快捷键说明 | 一行搜索与类型选择、内容分栏、轻量底部操作 |
| 列表摘要 | 两行正文，加时间与类型说明 | 单行摘要，保留日期分组、内容图标和收藏星 |
| 预览 | 默认按需打开 | 新布局默认展开并记住开关，宽左右／窄上下 |
| 大内容保护 | 文字超过 1 MiB、图片超过 16 MiB 显示摘要 | 额外限制 超过 20,000 字符的文本，防止长单行导航时同步布局 |
| 独立完整长文本 | 自动折行 | 长文本横向滚动，完整内容保留 |

以上是可检查的界面与行为变化；不据此推断使用效率或自动粘贴成功率提升。

## 本机验证记录

- Ubuntu 22.04.5 LTS／GNOME／X11，系统 Python 3.10 与 PyQt5；新建独立显示服务器 `:125`，不连接实际桌面剪贴板。
- 全量回归 **159 项，150 通过，9 项跨平台测试跳过**，耗时 22.643 秒。命令：`CLIPBOARD_ISOLATED_TEST=1 QT_QPA_PLATFORM=xcb python3 -m unittest discover -s tests -v`，DISPLAY 指向独立服务器。
- 主面板、预览、设置和小弹窗布局：**150%＋120 DPI 与 200%＋120 DPI 各 39 项全部通过**。使用合成记录覆盖浅深色、窄窗、中文混排与较大字体；主面板测试包含 10／16／20pt，预览和弹窗另覆盖至 26pt。
- 回归覆盖搜索／类型筛选、单行省略、日期与星标、默认预览和开关偏好、内容联动、较大内容按需读取、复制／粘贴快捷键及暂停／忽略状态。设置、目录迁移、原图和终端保护继续通过临时数据或隔离桌面检查。
- 本轮发现并修复高缩放、大字号下类型选择的文字空间不足：按实际样式的内容区和中文字形计算尺寸；修正后两个缩放组均通过。
- 增加字符数保护和长文本横向滚动，覆盖长单行 ASCII 文本，避免默认预览导航时隐式加载并折行大内容；复制、粘贴仍使用完整原记录。
- 已刷新并目视检查实际 Qt 浅色文字分栏（820×530）、图片预览、窄窗上下布局（451×680）及三页设置（600×560）。窄窗转换后可继续缩到 440；尺寸以逻辑像素记录。全部使用合成数据，没有读取或公开用户真实历史。

## 延续的验收边界

保留 500 MiB 默认容量、五档期限、收藏保护、原图、目录迁移和粘贴焦点约束。预览关闭与隐藏时释放内容。文本超过 20,000 字符或 1 MiB、图片超过 16 MiB 先显示摘要，明确打开后才加载完整内容；这些阈值控制预览成本，不限制已保存或复制的内容。完整长文本使用横向滚动，保存与复制保持完整原内容。

Codex 间歇粘贴、微信图片、日常截图、Windows 11、Mac Intel 的 macOS 14 基线、常用应用中文输入法、首次权限授权、睡眠恢复和真实登录自启动仍需对应使用场景验收。Windows 发布者签名和 macOS Developer ID 公证尚未完成，继续按工程预览发布。CI 成功不替代这些项目，Wayland 与其他 Linux 桌面不在已验证范围。
