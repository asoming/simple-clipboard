# 剪贴板应用 PRD

版本：v0.10

日期：2026-09-16
状态：0.4.0 历史管理迭代已通过三端自动化与安装包检查，公开工程预览已交付；签名稳定发行和实机验收尚未完成

暂定名称：剪贴板

## 1. 产品定义

一个简洁的桌面剪贴板工具，让用户快速找回复制过的内容，并准确粘贴到当前工作位置。

核心流程：**复制 → 自动记录 → 快捷键打开 → 搜索或选择 → 粘贴。**

### 1.1 已确认的要求

- 支持 Windows、macOS、Linux，分阶段实现与验证。
- Windows 最低 11，macOS 最低 14；Mac 覆盖 Intel 和 Apple Silicon，Windows 本轮提供 x64 包。
- Linux 首先适配用户现有电脑：Ubuntu 22.04.5 LTS、GNOME 42.9、X11；此为 2026-09-15 本机检查结果。
- 界面简洁，不花哨；日常操作尽量通过键盘完成。
- 优先完成快捷搜索、可靠粘贴、收藏和可控历史。
- 按三个阶段推进，每阶段完成验收再扩展范围。
- 已确认常用应用包括 Edge、Google Chrome、微信与终端；具体版本和测试范围见 [第一阶段验收报告](第一阶段验收报告.md) 和 [第二阶段验收报告](第二阶段验收报告.md)。

### 1.2 判断边界

- **事实：**现有系统和第三方产品已覆盖不少基础功能，历史记录本身不构成独特优势，见第 10 节。
- **待验证假设：**对本用户而言，更少的操作、更可靠的粘贴和更直观的历史管理，能够改善当前体验。
- **产品判断：**先服务本用户的真实工作流程，再判断是否对外发布；这不是已经确定的商业定位。
- **尚缺信息：**粘贴回微信等剩余场景的试用结果、可用 Windows/Mac 实机和签名发行条件；相应平台验收前需补齐。

## 2. 用户场景与目标

| 场景 | 用户希望得到的结果 |
|---|---|
| 连续复制多段内容后，需要找回前一段 | 不回到原软件重新寻找，直接从历史恢复 |
| 从网页复制到文档或聊天窗口 | 可以选择保留格式或使用纯文本 |
| 经常重复使用一段内容 | 收藏并命名，快速找到 |
| 截图后需要再次使用 | 能通过缩略图找到并再次粘贴 |
| 临时复制不想保存的内容 | 能暂停记录或忽略下一次复制 |
| 历史逐渐堆积 | 自动清理，同时清楚知道哪些内容会被保留 |

成功标准：用户能在实际工作中完成上述操作，不需要频繁回到原应用重复制，也不会因面板抢焦点、内容变化或静默丢失而失去信任。

## 3. 设计原则

1. **一个主面板：**顶部搜索，中间历史列表，底部简短快捷键提示。
2. **默认直接可用：**不要求登录、不要求建立分类、不弹出多步引导。
3. **少装饰：**使用系统字体、克制的间距和颜色；无渐变背景、营销卡片、装饰动画或首页仪表盘。
4. **信息够用：**文本显示简短摘要，图片显示小缩略图；选中后可查看完整内容。
5. **忠实保存：**不自动改写、翻译、补全或删除空白。纯文本粘贴是单独操作。
6. **状态明确：**暂停、容量不足、记录失败和权限缺失必须能被用户理解；避免连续弹窗。
7. **平台习惯一致：**三端功能含义相同，快捷键和系统集成遵循各平台习惯。

## 4. 三步路线

### 第一步：在本机跑通核心流程

进度：核心代码与自动化验证完成；用户真实环境验收待完成。[运行与使用说明](../README.md) · [验收报告](第一阶段验收报告.md)。

**目标：**在 Ubuntu / GNOME / X11 上完成可日用的文本剪贴板闭环，先验证兼容性与操作方式。

范围：

- 文本和链接自动记录；按最近复制时间排列。
- 全局快捷键呼出面板，可修改；检测到冲突或注册失败时提示。
- 文本搜索，支持中文和多行内容；搜索默认不区分英文字母大小写，不改变原文。
- 方向键选择、回车粘贴、Esc 关闭；提供“仅复制”操作。
- 同一内容重复复制时更新原条目的位置，不重复堆积。
- 收藏与命名、单条删除、完整文本预览。
- 本地保存、跨重启恢复、基础清理策略。
- 暂停记录、忽略下一次复制、明确的运行状态。
- 首次运行简短说明历史会在本地保存，以及如何暂停和删除。

**验收清单：**

- [ ] 从浏览器、编辑器和聊天输入框复制文本，可以完整找回，包括中文、换行和首尾空白。
- [x] 连续复制不同文本，历史顺序正确；重复复制不会产生无意义重复条目。
- [x] 搜索时中文输入法候选确认不会误触发粘贴（0.1.1 使用本机真实 IBus pinyin 验证）。
- [x] 搜索、选择、粘贴可只用键盘完成；Esc 关闭不改变当前剪贴板。
- [ ] 在已确认的常用应用中，粘贴返回原输入位置；操作不会发送消息或执行终端命令。
- [x] 不能自动粘贴时，用户仍可使用“仅复制”后手动粘贴，不声称已经粘贴成功。
- [x] 重启应用后，未过期历史和收藏恢复；暂停期间的内容不会在恢复时补录。
- [x] 删除、暂停、忽略下一次复制和容量限制均按第 6 节规则工作。

阶段出口：形成可安装或可重复启动的 Linux 测试版本，附实际测试应用及结果；未通过的核心兼容问题留在本阶段解决。

## 5. 交互约定

### 界面质量要求

- 简洁同时保持清晰的字号、间距和操作层级；避免所有操作都用同样醒目的边框。
- 中文和混排文字按实际字体测量行高，不使用固定文字矩形裁掉字形。长记录显示最多两行摘要，超出部分使用省略号，完整内容由「预览」查看。
- 主操作保留「仅复制」「粘贴」；预览、收藏与格式放在上一排。格式下拉框的文字与箭头分别留位。
- 在窄窗口、较大字体、100% / 150% / 200% Qt 缩放以及浅深色中检查。控件不可容纳时窗口最小尺寸随布局增加，至少能完整显示一条记录，列表与底部操作不得重叠；不能以裁字换取更小尺寸。
- 不使用真实历史作为公开预览或测试数据。界面渲染与实际系统输入法验收分开记录。

| 操作 | 预期行为 |
|---|---|
| 呼出快捷键 | 打开面板，搜索框可直接输入；默认选择最近条目 |
| 输入搜索词 | 过滤记录，匹配正文及收藏名称；无结果时保留搜索词 |
| 回车 | 关闭面板，尝试向打开面板前的目标窗口粘贴选中条目 |
| 仅复制 | 将选中条目放回系统剪贴板，不发送粘贴按键 |
| 纯文本粘贴 | 使用该条目的文本表示，不改变已保存的原始记录 |
| Esc | 关闭面板，不执行复制或粘贴 |
| 查看详情 | 显示完整文本或图片，不改变系统剪贴板 |
| 收藏 | 保留该条目，可填写名称；搜索能够找到它 |
| 重新打开面板 | 清空上一次搜索，回到最近记录，减少误选 |

具体全局快捷键在第一阶段检查本机冲突后确定；Windows/macOS 分别适配。面板不得额外发送 Enter、自动提交表单或执行内容。

v0.2 实现约定：默认 Ctrl+Alt+V，可在菜单修改。终端中的多行文本即使不额外发送 Enter 也可能执行，因此对已识别的终端仅复制并提示手动粘贴。编辑器内嵌终端和网页终端不作自动识别承诺，应使用「仅复制」。

## 6. 数据与隐私规则

下列为用户于 2026-09-16 确认的 v0.4 产品规则；容量与防护限制属于产品选择，不是系统统一上限。

- 普通历史默认保留 **30 天**，五档为 1 天、7 天、1 个月（30 天）、1 年（365 天）、无限期；无限期仅关闭按时间清理。默认不限制条数，可在设置中另行限制。
- 历史与收藏的内容数据默认合计 **500 MiB**；单条默认自动，受总容量约束，可手动设更小上限。索引等额外占用单独显示；500 MiB 不表示运行内存限额。
- 达到容量预算时，先移除最旧的未收藏条目；收藏不自动淘汰。如果仍不足，跳过新条目并提示原因。
- 重复项以内容及支持的格式表示判断；不能仅凭预览文字相同就合并不同格式或不同图片。
- 应用自身的历史回填不生成重复记录。原始图片按完整字节判断重复；元数据不同的原图分别保留，以免损失原始信息。
- 暂停后停止采集，恢复时以当时剪贴板作为基线，等待下一次变化，避免补录暂停期间的内容。
- “忽略下一次复制”指忽略下一次可观测的外部剪贴板更新；界面显示等待状态并允许取消，不承诺识别没有产生变化的复制按键。
- 默认不上传内容、搜索词或使用记录；产品没有账号和后台同步。
- 敏感类型排除仅在系统或来源应用提供可靠信号时生效，不承诺识别全部密码和密钥；手动暂停始终可用。
- “清空历史”默认保留收藏；提供含收藏的全部删除选项并二次确认。单条删除不反复弹窗。
- 删除记录时同步清理关联预览和索引；清空系统当前剪贴板作为明确选项，避免用户误以为删除历史等于清空系统剪贴板。
- 本地存储不等于加密。首版不宣称能防止同账户恶意程序访问，也不把普通删除描述为安全擦除；加密需求另行评估。
- 文件复制、剪切移动语义、应用专有对象不属于本版支持范围；管理器不得擅自把它们转换为文字后覆盖系统剪贴板。

## 8. 质量与验证

### 8.1 核心兼容性

开发前确定实际应用名单。建议覆盖浏览器、编辑器、聊天软件、办公软件和终端；未安装的应用不虚构测试结果。

测试记录包含：系统和应用版本、来源应用、内容类型、目标应用、操作步骤、实际结果、限制与复测状态。

重点验证：中文输入法、长文本、换行与缩进、重复复制、焦点返回、暂停恢复、容量清理、图片格式，以及更新后数据仍可读取。

### 8.2 性能目标

以下为待测的工程目标，不作为已有结果：

- 在本机、500 条混合历史下，常驻状态呼出面板到可输入的第 95 百分位耗时目标不超过 **200 ms**。
- 同条件下，输入搜索词到结果刷新目标不超过 **100 ms**（第 95 百分位）。
- 测量空闲 CPU、内存、存储占用及图片导入峰值；第一阶段取得基线后确定资源预算，不预设未经测试的“极低占用”承诺。
- 自动粘贴按场景逐项通过，不用未经支持的“成功率 99%”代替兼容名单。

### 8.3 完成定义

一个功能只有在正常路径、关键失败路径和对应验收项均验证后才标记完成。只实现界面、只编译成功或只在单个应用里演示，不等于完成。

## 9. 按 PRD 推进的流程

每个阶段使用同一流程：

1. **列出本阶段任务：**关联 PRD 条目，明确输入、输出与验收方式；补齐会阻塞实现的信息。
2. **验证关键风险并实现：**先做监听、焦点和格式等关键验证，再补齐界面；技术框架根据结果选择。
3. **验收与试用：**记录已完成、未通过、已知限制和真实用户反馈。
4. **更新 PRD：**修改需求时写明原因、受影响范围及新版本号，然后进入下一阶段。

阶段出口是质量检查点，不额外设置每项操作的确认流程。用户确认中文输入修复可用并授权进入第二阶段。第二阶段已交付 0.2.0 测试版。用户授权进入第三阶段，现推进 0.3.0 预览，继续记录未完成的真实使用验收。

实现时允许共享数据模型和界面逻辑，但平台监听及粘贴能力分别验证。若现有开源项目能满足范围，应比较改造与新建的维护成本，再作选型决定。

## 11. v0.4 历史管理需求与验收

- 按本地日期分组，今天、昨天、完整日期；组内新记录在前，搜索和图片/收藏筛选沿用分组。
- 每条右侧提供空心五角星，单击立即收藏并显示黄色；再次点击取消。保留键盘可操作的收藏按钮和右键重命名。星标单击/双击不能触发粘贴。
- 原图：保存来源提供的第一种受支持编码图像原始字节，预览和粘贴支持原格式；仅有像素时保存 PNG。保留颜色、尺寸、元数据；生成的缩略图与原图分离。不声称恢复来源未提供的原文件或旧版已丢弃的信息。保留 2400 万像素解码保护，超限明确跳过而不缩图。
- 默认登录自启动：实际应用首次运行启用，用户关闭后不再次自动启用。权限或外部配置冲突时明确提示且可重试。测试和安装包自检不得创建用户启动项。
- 空间页：蓝色普通记录、黄色收藏、灰色剩余容量；显示内容预算和实际数据库大小。
- 内存页：显示当前进程常驻内存/工作集，每 2 秒取样，最多保留 60 点；图表纵轴从 0 起并标注动态上限。仅打开窗口时采样。
- 回收文件空闲空间只整理已经空出的数据库页面，不删除现有历史。释放缓存只清除可回收缓存，不删除记录或系统剪贴板，不承诺内存立即下降。删除历史沿用独立确认流程。
- 升级：数据库版本 3，旧版拒绝打开；保留全部记录、收藏和自定义保存规则。完整旧默认规则才迁移到新默认规则。后续规则变更不得悄悄缩短用户自定义期限。
- 验证：自动容量、无限期仍受容量约束、收藏保护、跨日搜索与键盘选择、星标避免误粘贴、PNG/JPEG/BMP 字节往返、自启动默认与退出、清理不删记录、窄窗口/高字号布局。

### 参考与边界（2026-09-16 核查）

- [微软剪贴板帮助](https://support.microsoft.com/en-us/windows/apps/using-the-clipboard)：4 MB 针对系统历史功能，不能推断普通复制粘贴也有同样上限。
- [Windows 剪贴板操作](https://learn.microsoft.com/en-us/windows/win32/dataxchg/clipboard-operations)：通过内存对象传递，应用可提供多种格式；未据此虚构所有平台共同的单条上限。
- [X11 ICCCM](https://xorg.freedesktop.org/archive/X11R7.7/doc/xorg-docs/icccm/icccm.html)：大数据可通过 INCR 分段传输，协议最大请求长度不等于内容上限。
- [Windows 内存计数器](https://learn.microsoft.com/en-us/windows/win32/api/psapi/ns-psapi-process_memory_counters)：WorkingSetSize 是当前工作集字节数。Linux 使用 /proc/self/statm 常驻页，Mac 使用 ps 的 RSS；平台口径并非严格等价，不作为跨系统性能排名。

## 12. 设置窗口可读性修复（0.4.1）

设置弹窗必须显式继承主界面中文字体，并按实际字形和最长选项测量控件，不能依赖默认字体的名义行高。内容区可滚动，保存和取消始终留在窗口底部；窄窗口允许表单换行。验收必须单独打开设置页，覆盖字体、样式、缩放、说明与错误提示，不能用主面板测试代替。详见 [设置窗口修复验收](设置窗口修复验收.md)。
