# 剪贴板应用 · 第二阶段验收报告

日期：2026-09-15  
应用：0.2.0；PRD：v0.4  
结论：**第二阶段功能已实现，本机技术验证通过，已验证本机启动。进入真实工作流程试用，尚未开始第三阶段。**

## 1. 已交付

| PRD 功能 | 结果 |
|---|---|
| 图片记录、缩略图、原图预览、粘贴 | 静态 PNG；原始尺寸可滚动查看；浏览器与外部 Qt 图片链路通过 |
| 原格式 / 纯文本 | 原格式保留来源 HTML 或图片；纯文本只提供原有文字，不带来源 HTML |
| 简单筛选 | 全部、文本、图片、收藏；图片可收藏命名并按名称搜索 |
| 清理与容量 | 时间、普通历史条数、总内容容量、单条上限可设置；展示内容与数据库文件占用 |
| 收藏保护 | 收藏不自动淘汰；拒绝小于收藏占用的总容量；设置失败回滚测试通过 |
| 外观与基础操作 | 跟随系统、浅色、深色；中文搜索、键盘操作、空状态、错误提示 |
| 可选自启动 | 默认关闭；配置生成、禁用与路径转义在临时目录测试通过；真实登录待验收 |
| 隐私控制 | 暂停、忽略下一次、已支持的敏感 MIME 标记；取消未处理完的记录任务 |
| 旧版数据升级 | 合成 v1 数据迁移后文本、收藏名称、ID 和设置保留；模拟中途失败时 schema 和数据回滚 |

**格式解释：**纯文本会去掉来源样式，但目标编辑器可以沿用光标处的样式。图片不保留作者和 DPI 元数据，保留像素及颜色配置；不做 OCR。HTML 预览只显示文字，不加载网页资源。RTF、文件、专有对象、动画不作支持承诺。

**应用排除名单暂未实现。** 尚未完成可靠的来源识别验证；当前前台应用不一定是剪贴板来源，不能据此给出有误导性的排除功能。

## 2. 测试证据

所有复制粘贴自动化均使用独立 Xephyr X11 桌面与自造内容。测试未读取、输出或打包真实历史数据库。真实输入法测试使用独立空白输入框，不监听或修改剪贴板，结束后恢复此前焦点。

### 自动化与迁移

- **50 项测试通过**：[完整结果](../verification/tests.log)。覆盖历史、搜索、收藏、清理、锁、输入法保护、旧库迁移与失败回滚、图片/HTML 往返、容量拒绝、队列取消、外观与设置。
- 原图预览另行验证：连续打开 3 次，原始尺寸为 1800 × 1200；关闭后对话框被释放，避免持续保留大图。
- 图片分辨率超限、编码后超过容量、损坏图片与敏感 MIME 标记均覆盖失败路径。
- 图片作者、DPI、设备缩放元数据不同而像素相同时，归一化后去重验证通过。
- 实际旧版进程已退出，新版正常启动；重复运行启动器返回已运行窗口。未通过读取真实历史内容来核对升级前后逐条数据，保留性证据来自事务实现和合成迁移测试。

## 3. 性能

数据集为 **500 条混合历史**：250 条约 750 字节文本、150 条短 HTML、100 张 320 × 200 随机像素 PNG。内容约 26.59 MiB，数据库文件约 27.17 MiB。测量在本机 Xephyr X11 中进行，界面已预热；每项 40 次，P95 取排序后第 38 个样本。

| 指标 | 实测 | 判断 |
|---|---:|---|
| 全局快捷键到搜索框获得焦点 P95 | 93.11 ms | 低于 200 ms 目标 |
| 打开面板并处理 Qt 绘制 P95 | 77.91 ms | 应用内部耗时 |
| 输入搜索词到列表刷新和绘制 P95 | 4.85 ms | 低于 100 ms 目标 |
| 空闲 CPU，短时约 2 秒采样 | 单核的 1.52% | 短时样本，不作长期功耗结论 |
| 导入大条目前的进程峰值 RSS | 160.25 MiB | 包含测试数据构造，不等于常驻内存 |
| 导入大条目后的进程峰值 RSS | 272.49 MiB | 包含测试图片、转换中间数据及大文本 |
| 3840 × 2160 纯色图片处理与记录 | 350.05 ms | 最大界面计时器间隔 108.09 ms |
| 8 MiB 文本处理与记录 | 131.27 ms | 最大界面计时器间隔 131.32 ms |

[原始性能结果](../verification/performance.json)。计时器间隔用于观察处理期间主线程响应，不等同于每次键盘输入延迟。

**测量限制：**包括 X11 快捷键、Qt 焦点与绘制，不包括用户 GNOME 桌面合成器的实际延迟；不是端到端日用性能的完整证明。纯色大图易压缩，不代表照片、所有尺寸或所有来源应用。剪贴板最初的 MIME 读取仍依赖来源应用响应，因此不能承诺任何来源都不阻塞。当前资源使用不能描述为“极低占用”。

## 4. 试用清单

以下保持待验收，不能因实现完成而自动勾选：

- [ ] 平时的截图方式 → 历史缩略图 → 原图预览 → 微信图片草稿；确认不会自动发送。
- [ ] 微信图片 → 历史 → 支持图片的编辑位置；确认实际应用接受该格式。
- [ ] 在日常网页编辑器中切换原格式、纯文本，确认符合目标位置的预期。
- [ ] 日常大图与较多历史下连续使用，观察响应与内存。
- [ ] 如需要自启动，手动启用后实际退出并重新登录桌面验证。

本轮没有启用系统自启动。运行于受限环境时，设置可能无权写入系统自启动目录；界面会提示失败。配置代码已用临时目录验证，**不把该测试等同于真实登录成功**。

### 实现依据

- 自启动文件与 Exec 参数转义遵循 [freedesktop Desktop Entry Specification](https://specifications.freedesktop.org/desktop-entry/latest-single/)。
- 系统外观读取使用 [XDG Settings Portal 的 color-scheme 定义](https://github.com/flatpak/xdg-desktop-portal/blob/main/data/org.freedesktop.portal.Settings.xml)，支持变化通知；缺少系统偏好时回退到 Qt 调色板。
- 输入法修复沿用 0.1.1 的 IBus 门户处理，问题依据与第一轮实测见 [第一阶段验收报告](第一阶段验收报告.md)。
