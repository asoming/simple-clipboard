## 范围与依据

用户确认以 Raycast 为主要设计参考。本轮整理主面板、按需内容预览、分组设置与各类弹窗；保留原有容量、期限、收藏、原图、保存目录迁移、粘贴焦点与隐私约束。需求基线为 [PRD v0.12](剪贴板应用-PRD.md) 第 14 节。

本轮不增加账号、云同步、OCR、加密或数据恢复功能。参考竞品是设计判断，不代表已经完成竞品实测或证明效率提升。

## 延续的验收边界

Codex 间歇粘贴、微信图片与实际截图仍需用户工作流程验证。Windows 11、Mac Intel 的 macOS 14 基线、常用应用中文输入法、首次权限授权、睡眠恢复、真实登录自启动与发行签名尚未全面完成；CI 成功不替代这些项目。Wayland 与其他 Linux 桌面不在已验证范围。

## 本轮实现要点

- 主列表保留两行摘要，日期使用细分隔，统一内容图标、行尾星标和选择态；浅深色共用同一套间距和控件规则。
- 底部操作在较窄窗口换行；内容预览可收起，宽窗口并排、窄窗口上下排列，主面板隐藏时清除缓存。
- 文本超过 1 MiB、图片超过 16 MiB 时先显示摘要，明确点击后才读取完整内容；不改变保存或复制的数据。完整大内容的打开速度仍受内容规模影响。
- 设置分为常规、历史与存储、空间与内存；每页独立滚动，保存/取消固定。较少使用的条数和单条限制可展开。
- 修复说明文字扩大宽度后不缩小高度的问题，并统一清空、名称输入、快捷键和完整预览弹窗。

## 本机验证记录

- Ubuntu 22.04.5 LTS / GNOME / X11，系统 Python 3.10 与 PyQt5；新建隔离显示服务器 `:124`，不连接实际桌面剪贴板。
- 全量测试：154 项，145 通过、9 项跨平台测试跳过。命令：`CLIPBOARD_ISOLATED_TEST=1 QT_QPA_PLATFORM=xcb python3 -m unittest discover -s tests -v`（DISPLAY 指向隔离服务器）。
- 主面板、预览、三页设置与小弹窗布局：150% 与 200% 缩放、120 DPI 各运行 34 项通过。测试覆盖浅深色、窄窗、不同字号（主面板 10/16/20pt，预览与小弹窗 10/20/26pt）及中英文混排。
- 增加短屏幕展开预览不越界、展开前不加载完整数据、隐藏后释放内容、大文本先展示摘要、说明文字随宽度缩回高度、预览快捷键、复选项可点击和设置页采样启停回归。
- 已目视检查合成的浅深色主面板、文字与图片预览、三页设置，以及清空弹窗；没有使用或公开用户真实记录。
