# 第三阶段验收报告

版本：0.3.0 工程预览 · 日期：2026-09-15

**结论：0.3.0 工程预览完成，三端自动化和安装包检查通过；正式签名与用户实机验收仍未完成，第三阶段不能标记为全部验收通过。**

## 1. 本轮交付

- Windows 原生全局快捷键、原窗口核对、Ctrl+V、托盘及当前用户登录启动。
- macOS Intel / Apple Silicon 后端：菜单栏、默认 Cmd+Shift+V、后台剪贴板变化检测、原应用及窗口核对、Cmd+V、辅助功能权限说明和用户登录启动。
- Linux 保留 X11 实现，回归此前文字、HTML、图片、中文搜索与终端保护流程。
- 安装目录与用户历史分离。旧源码版继续使用原数据；安装版可从菜单导入旧数据库，拒绝覆盖非空历史，失败保留原件。
- 清空历史可同时删除收藏、重置设置、关闭自启动并退出；系统当前剪贴板单独选择是否清空。卸载默认保留历史。
- Ubuntu deb、Windows 用户级 setup.exe、两种 Mac 架构的 dmg；附对应开源依赖源码及版本、哈希清单。

界面仍保持搜索、四个筛选、预览和少量菜单操作；未引入账号、云同步、OCR 或复杂分类。

## 2. 自动化验证

代码提交：`06de6c0`。本轮记录见 [GitHub Actions](https://github.com/asoming/simple-clipboard/actions/runs/34938338697)。全部使用合成数据，没有读取、导出或打包用户的实际剪贴板历史。

| 环境 | 原生验证范围 | 安装包验证 |
|---|---|---|
| Ubuntu 22.04 X11 | 原有桌面流程、导入失败保护、中文候选确认、单实例与数据清理 | deb 安装、启动、重装、卸载 |
| Windows Server 2025 x64 | 外部复制、快捷键与冲突、原窗口粘贴、不发送回车、HTML/纯文本/图片、重复启动、注册表启动项 | setup 安装、启动、重装、卸载；合成历史哈希保持不变 |
| macOS 14 Apple Silicon | 后台文字/HTML/图片、暂停/忽略、快捷键与冲突、连续粘贴及修饰键释放、原窗口、重复启动、权限拒绝分支 | .app 启动、ad-hoc 签名完整性；dmg 挂载、复制后启动 |
| macOS 15 Intel | 与 Apple Silicon 相同的原生测试 | .app 启动、dmg 挂载、复制安装后启动 |

每个环境发现 75 项测试：Linux 66 项通过、9 项跳过；Windows 53 项通过、22 项跳过；两种 Mac 各 54 项通过、21 项跳过。系统不适用的测试明确跳过，不计为通过。见 [验证摘要](../verification/phase3-ci-summary.json)。

自动化中的中文输入法检查使用构造的 Qt 组合/提交事件，证明候选确认不会误触粘贴；**不等于 Windows/Mac 系统拼音输入法已实测**。已有 Linux 真实 IBus 拼音结论沿用前阶段记录。

测试时发现并修复：Mac 通信路径过长、Windows 测试数据库句柄未关闭、Mac 连续粘贴后修饰键状态残留、旧自启动项显示不准确，以及跨系统读取配置的编码差异。图片接收测试使用明确支持图片 MIME 的独立编辑器；不把普通文本框当作图片接收端。

## 5. 已知行为与边界

- Mac 每 150 毫秒检查变化计数；同一次检查间隔内被多次覆盖的中间内容可能错过。
- Mac 拒绝辅助功能权限时仍可保存、搜索和仅复制。没有主动申请屏幕录制或输入监控；无法确认原窗口则手动粘贴。
- Windows 尊重前台切换和 UIPI 权限限制，不提权向管理员应用注入按键。
- 终端识别依赖进程/窗口信息；编辑器内嵌或网页终端不能可靠识别。已识别终端的多行文本、图片保持仅复制。
- HTML 取决于源应用提供的格式；图片归一化为 PNG。RTF、文件对象、动态图片不在承诺范围。
- 清理与卸载不等于介质安全擦除；用户备份和系统剪贴板有各自生命周期。
